# Aula 12 — API com Python

Projeto desenvolvido durante a disciplina de **Computational Thinking with Python**, na FIAP.

## 📚 Objetivo

Praticar a criação de uma API utilizando Python, trabalhando com rotas HTTP e operações de manipulação de dados.

## 🚀 Tecnologias utilizadas

* Python
* Flask
* Flask-RESTX
* Swagger
* VS Code
* Git e GitHub

## ⚙️ Funcionalidades

A API permite realizar operações relacionadas ao gerenciamento de usuários, como:

* Listar usuários
* Buscar usuário por ID
* Cadastrar usuário
* Atualizar usuário
* Excluir usuário

## ▶️ Como executar

Instale as dependências necessárias e execute:

```bash
python app.py
```

A aplicação será iniciada localmente na porta `5000`.
